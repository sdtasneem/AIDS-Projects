# Indian Kids Screen Time Analysis

## Project Overview

This project analyzes screen-time patterns among Indian children using exploratory data analysis (EDA).

The analysis focuses on understanding how children use different devices, how screen time varies across demographic groups and regions, and the relationship between educational and recreational screen use and reported health impacts.

## Dataset

The project uses the **Indian Kids Screen Time** dataset.

The notebook performs data inspection, cleaning, preprocessing, and exploratory analysis on the dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook / Google Colab

## Data Analysis Workflow

### 1. Data Loading

The dataset is loaded into a Pandas DataFrame for analysis.

### 2. Data Inspection

The dataset is explored to understand:

- Dataset structure
- Column names
- Data types
- Dataset dimensions
- Summary statistics

### 3. Data Cleaning

The notebook performs data-cleaning steps including:

- Checking for missing values
- Handling missing values
- Checking and removing duplicate records
- Identifying potential data-quality issues

### 4. Exploratory Data Analysis

The project analyzes screen-time patterns across different dimensions.

### Device Usage

Screen-time usage is analyzed across different devices to understand which devices are used more frequently by children.

### Gender Analysis

Screen-time patterns are compared across genders.

### Age Analysis

The analysis examines how screen time varies across different age groups.

### Educational vs. Recreational Screen Time

Educational and recreational screen-time usage are compared to understand how children's screen exposure is distributed between learning and entertainment.

### Health Impact Analysis

Reported health impacts are analyzed in relation to children's screen-time patterns.

### Urban vs. Rural Analysis

Device usage and screen-time patterns are compared across urban and rural regions.
