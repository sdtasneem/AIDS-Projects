# Breast Cancer Prediction using ANN

## Project Overview

This project uses an Artificial Neural Network (ANN) to predict whether a breast tumor is **Malignant** or **Benign** based on diagnostic features.

The project follows an end-to-end machine learning workflow, including data preprocessing, categorical encoding, feature selection using Recursive Feature Elimination (RFE), feature scaling, ANN model development, training, evaluation, model saving, and prediction on new input data.

## Dataset

The project uses the **Breast Cancer Wisconsin Diagnostic Dataset** from Kaggle.

Dataset source:
https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data

## Machine Learning Workflow

### 1. Data Collection
The Breast Cancer Wisconsin dataset is downloaded from Kaggle and loaded into a Pandas DataFrame.

### 2. Data Exploration
The dataset is explored using:
- `head()`
- `info()`
- Missing-value analysis
- Dataset inspection

### 3. Data Preprocessing
The following preprocessing steps are performed:
- Removal of the unnecessary `Unnamed: 32` column
- Conversion of categorical values into numerical values using `LabelEncoder`
- Separation of input features and target variable

### 4. Feature Selection
Recursive Feature Elimination (RFE) with a Random Forest Classifier is used to select the **top 5 important features**.

### 5. Train-Test Split
The selected features are divided into:
- **80% Training Data**
- **20% Testing Data**

### 6. Feature Scaling
`StandardScaler` is applied to normalize the selected features before they are provided to the ANN model.

The trained scaler is saved as:
```text
scaler.pkl
```

### 7. ANN Model
An Artificial Neural Network is developed using TensorFlow and Keras.

The architecture consists of:
- Input layer
- Dense layer with 32 neurons
- Dense layer with 16 neurons
- Dense layer with 8 neurons
- Output layer with 1 neuron and sigmoid activation

### 8. Model Training
The ANN model is trained using:
- **Optimizer:** Adam
- **Loss Function:** Binary Cross-Entropy
- **Epochs:** 50
- **Batch Size:** 32
- **Validation Split:** 20%

### 9. Model Evaluation
The trained model is evaluated on unseen test data using classification accuracy and loss. Training and validation performance are visualized using Matplotlib.

### 10. Model Saving
The trained model and preprocessing components are saved for future predictions:
```text
breast_cancer_prediction.h5
scaler.pkl
selected_features.pkl
```

### 11. Prediction
A reusable prediction function:
1. Loads the trained model
2. Loads the saved scaler
3. Loads the selected features
4. Accepts new input values
5. Scales the input
6. Generates a prediction probability
7. Classifies the result as **Malignant** or **Benign**
