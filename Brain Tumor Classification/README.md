# Brain Tumor Classification using CNN

## Project Overview

This project uses a Convolutional Neural Network (CNN) to classify brain MRI images into four tumor classes.

The project covers the complete workflow from dataset extraction and image preprocessing to CNN model training, early stopping, model saving, and prediction on a new MRI image.

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- PIL
- Google Colab

## Dataset

The project uses a Brain Tumor MRI dataset organized into separate **Training** and **Testing** directories.

The dataset contains four classes:

- Glioma
- Meningioma
- Pituitary Tumor
- No Tumor

### Dataset Source

[Kaggle - Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset)

## Workflow

### 1. Dataset Preparation

The compressed dataset is extracted and the available project files are checked.

### 2. Image Preprocessing

`ImageDataGenerator` is used to normalize the image pixel values.

Training and testing images are loaded using `flow_from_directory()`.

Images are:
- Resized to 224 × 224 pixels
- Converted to grayscale
- Normalized by rescaling pixel values from 0–255 to 0–1
- Loaded with categorical labels

### 3. Data Visualization

Sample training images are displayed with their corresponding class labels to verify image loading and label assignment.

### 4. CNN Model

The CNN architecture consists of:

- Input layer for 224 × 224 grayscale images
- Conv2D layer with 32 filters
- MaxPooling2D
- Batch Normalization
- Conv2D layer with 64 filters
- MaxPooling2D
- Batch Normalization
- Flatten layer
- Dense layer with 64 neurons
- Dropout layer with 0.2 dropout rate
- Softmax output layer with 4 classes

### 5. Model Compilation

The model is compiled using:

- **Optimizer:** Adam
- **Loss Function:** Categorical Cross-Entropy
- **Metric:** Accuracy

### 6. Model Training

The CNN is trained for a maximum of 50 epochs.

Early stopping is applied by monitoring validation loss. Training stops when the validation loss does not improve for 5 consecutive epochs, and the best model weights are restored.

### 7. Model Saving

The trained model is saved as:

```text
Brain Tumor.keras
```

### 8. Prediction

A prediction function is created for a new MRI image.

The input image is:

1. Converted to grayscale
2. Resized to 224 × 224
3. Normalized
4. Converted into the required CNN input shape
5. Passed to the trained model

The model returns:

- Predicted tumor class
- Prediction confidence
